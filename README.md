# 🎬 Sériescope – Catalogue de séries TV

**Sériescope** is a web application that allows users to explore, search, filter, and add TV series to a dynamic catalogue.

The project provides a simple and modern interface to discover TV shows and organize them by genre.

## 🌐 Live Demo

👉 [Visit Sériescope](https://elidrissiibrahim.github.io/S-rieScope-catalogue-de-s-ries-et-documentaires/)

## ✨ Features

- **Dynamic Catalogue:** Display TV series dynamically.
- **Search:** Find series by their names.
- **Genre Filter:** Filter series according to their genres.
- **Add a Series:** Add new series with a name, genres, and description.
- **Reset Filters:** Reset the search and genre filters.
- **Responsive Design:** Adapted to different screen sizes.
- **API Integration:** Retrieve TV series data using the TVmaze API.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **Tailwind CSS** – Styling and responsive design.
- **JavaScript (ES6+)** – Dynamic content and application logic.
- **TVmaze API** – TV series data.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/elidrissiibrahim/S-rieScope-catalogue-de-s-ries-et-documentaires.git
```

2. Open the project folder:

```bash
cd S-rieScope-catalogue-de-s-ries-et-documentaires
```

3. Open `index.html` in your browser.

## 🔗 API

This project uses the [TVmaze API](https://www.tvmaze.com/api) to retrieve TV series information.
